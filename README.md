# Fonesio · 销售推广配额查询（基础版）

静态单页，无构建、无依赖。视觉取自设计方案「第二排第一个 · 红橙促销风」。

## 运行

```bash
cd ~/Desktop/Fonesio
python3 -m http.server 4450 --bind 127.0.0.1
# 打开 http://127.0.0.1:4450/
```

直接双击 `index.html` 也能看，但用本地服务器更接近真实环境。

## 结构

```
index.html            页面骨架
assets/css/style.css  全部样式（红橙渐变 + 卡片 + 响应式）
assets/js/app.js      省份数据、随机额度、动态刷新、搜索
preview.png           当前渲染截图
```

## 已实现

- 顶部深红栏：左侧为上传的 `Fonesio 风意逍` 白色字标（assets/img/logo.png），右侧导航已移除
- 红橙渐变标题区 + 波浪装饰，居中主标题「全国各省份配额余量实时查询」
- 白色圆角搜索容器（20px 圆角、浅灰描边、72px 高）+ 红色线性放大镜 + 右侧红色圆角「搜索」按钮，按钮内嵌留白；支持省/市/自治区后缀与简写（如「广东」「广东市」）
- 34 个地区卡片，五列网格；按剩余名额升序排列，告急的排前面
- 卡片字号上调：省名 18px、说明 13px、数字 56px、单位 14px、状态标签 13px
- 数字使用 **DIN Next LT Pro Medium**（`assets/fonts/din-next-lt-pro-medium-digits.woff2`，仅含 0-9 与 , . 子集，与 ChatShot 同款）
- 状态标签三档：`紧急！仅剩 N 个` / `名额紧张` / `即将告罄` / `名额有限`；标签 15px / 800 字重、内边距 7×19
- 悬停或搜索命中时卡片放大（悬停 1.10、选中 1.12），标签内出现自左向右的流光
- 选中模式：命中卡片放大 1.12 + 红色描边圈；点击页面其他任意位置或按 Esc 退出选中
- 流光速度随告罄程度变化：1–2 个 0.7s、3–4 个 1.0s、5–6 个 1.4s、7–8 个 1.9s、9–10 个 2.5s；流光位于文字之下并加文字投影，不影响可读性
- 名额区间固定 **1–10**（初始随机偏低位，制造紧迫感）
- 每 3 秒模拟一次名额占用：多数递减 1，小概率补放（含见底省份回补 2–5），数字带跳动动效
- 数字变化时卡片触发「闹钟式」左右快速抖动（0.55s，8 段衰减，`prefers-reduced-motion` 下关闭）
- 数字本身老虎机式滚动：旧值向上滑出、新值从下方滑入（340ms；位数变化时临时撑宽避免裁切）
- 右下角固定悬浮「回到顶部」按钮：滚动超过 360px 淡入，点击平滑回顶，≤860px 自动缩小
- `?debug=1` 会暴露 `window.fonesioDebug.setCount(state, n)`，用于手动验证滚动动画
- 搜索命中：卡片红框高亮 + 平滑滚动 + 提示条；未命中：底部 toast 提示
- 响应式：≤1080px 四列，≤860px 三列，≤560px 两列
